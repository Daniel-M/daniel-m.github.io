TL;DR
  • multer-dos is a multer storage engine for DigitalOcean Spaces.
  • Has about 10 weekly downloads per week, deserved revamping

For context check an old post

To keep things short, I’ve been doing some software archeology on my pasts projects. I noticed that my opensourced project https://github.com/Daniel-M/multer-dos was getting about 10 downloads a week on the npm registry https://www.npmjs.com/package/multer-dos so i decided to add support for typescript and dependency updates. The project is so easy to maintain, I guess part of the 10 downloads per week means this is still used in production by some people, so thanks for believing in me
