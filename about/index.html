What am I proud of? Link to heading

I really like the person I am and the life I have built. I’m proud of my grit, initiative, and creativity in getting things done.

As a software engineer, I’m proud of:

  • A clothing product ingestion pipeline (2019–2021). I built and maintained a scheduled, multi-step web-scraping and ETL pipeline for a fashiontech startup. It ingested products from more than 10 clothing brands, feeding thousands of items with descriptions and images to a replicated database, preventing duplicates. I wrote tailored Elasticsearch scripts to rate, classify, and index the clothing. I also maintained an applied AI pipeline that extracted product attributes from images to power a recommendation system, and fine-tuned PyTorch models for clothing classification.

  • An algorithm migration for a fintech. I migrated an algorithm from one language to another. When I found an apparent bug, I traced it to a flaw in the client’s original algorithm.

  • An IoT data backend (2021–2022). I built a GraphQL backend (Apollo) and a RESTful ingestion API with a small memory footprint. I split the backend into an Apollo server on Node.js and a Go REST API, to get faster responses and faster ingestion. The Go REST API cut response time from about 500ms to about 120ms per request.

  • Full-Stack Platform Engineer, Titan Intake (2023–2026). I engineered core platform features for a high-availability, multi-tenant healthcare SaaS platform in an AI-first environment, spanning serverless microservices, applied AI with MLOps pipelines, and EMR interoperability. My work included a Document Packets Engine for AI-based document routing and atomic batch FHIR transactions, Document Intelligence workflows built on LLMs and NLP classification, and an automated LLM evaluation framework that benchmarks prompt variants and model swaps through repeated statistical experiments, feeding an MLOps pipeline that reports service quality metrics. This protocol caught a regression before it hit production. More details are on my CV.

As a physicist, I’m proud of working with computer simulations and experimental data. I’m really proud of my equation to calibrate fluorescence signals, which was published in the Journal of Muscle Research and Cell Motility “A new set of equations for the simplified calibration of fluorescence Ca2+ transients in skeletal muscle fibers”.
